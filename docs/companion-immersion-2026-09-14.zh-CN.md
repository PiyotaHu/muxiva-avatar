## 中文朗读内容

修复在本地 TTS 使用的 `python/muxiva_avatar_speech/speech_text.py`，不在 Agent 提示词中绕开：

| 输入 | 原问题 | 修正后的合成文本 |
| --- | --- | --- |
| `1，2，3，4，5` | 合并成一万二千三百四十五 | 一，二，三，四，五 |
| `今天25，明天26` | 数字后的逗号丢失 | 今天二十五，明天二十六 |
| `25℃` / `25°C` | 可能留下字母 C | 二十五摄氏度 |
| `77℉` / `77°F` | 温度单位未完整展开 | 七十七华氏度 |

合法 ASCII 三位分组仍按千分位处理；中文逗号、emoji 停顿、不合法分组不会被合并。显式英文路径保留英文，自动语言识别不把裸温度中的 C/F 当成英文句子。

这修正读字和标点，不证明音色自然、有情感。ASCII `1,234` 有语义歧义，按合法千分位处理；七位及以上整数逐位朗读的启发式未动，数量与号码仍需区分。
